Developing Embryonic Octopus Arm Nervous System

All code was used to generate and analyze the data presented in the following paper:
Elagoz AM, Van Dijck M, van Rooij E, Deryckere A, Neacsu D, Seuntjens E. (Year) Developing Embryonic Octopus Arm Nervous System. [Journal Name]. DOI: [10.xxxx/xxxxx]

Repository Content:
DEseq2.R includes the code used to analyze QuantSeq 3' RNAseq data and identify differentially expressed genes among the octopus embryonic developmental stages XI, XIV, and XX.
